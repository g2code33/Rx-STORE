# Cloudflare — Safe Deployment for Rx Store

> **Rule:** Never modify `pharmagame-*` or `code-rx-*` resources. All Rx Store resources use `rx-store-*` prefix.

## 1. Resources to Create

```bash
# Login
npx wrangler login

# D1 (isolated DB)
npx wrangler d1 create rx-store-db
# → copy database_id into backend/wrangler.toml

# R2 (isolated bucket)
npx wrangler r2 bucket create rx-store-storage

# KV (cache)
npx wrangler kv:namespace create rx-store-cache
npx wrangler kv:namespace create rx-store-cache --preview

# Verify isolation — should show separate DBs/buckets
npx wrangler d1 list
npx wrangler r2 bucket list
```

## 2. Initialize Database

```bash
npx wrangler d1 execute rx-store-db --file=backend/schema.sql
# Seed verified: 5 apps inserted (clinical-rx, pharmagame, code-rx-society, tawomo, curelink)
```

## 3. Create R2 Folder Structure

No folders needed in R2 (flat keys), but use these prefixes:

```
apps/clinical-rx/android/
apps/clinical-rx/windows/
apps/clinical-rx/linux/
apps/pharmagame/...
apps/code-rx/...
apps/tawomo/...
apps/curelink/...
assets/icons/
assets/screenshots/
assets/videos/
assets/documents/
releases/versions.json
```

Upload via `wrangler r2 object put` or dashboard. Signed URLs generated by Worker.

## 4. Set Secrets (Worker)

```bash
npx wrangler secret put JWT_SECRET --config backend/wrangler.toml
npx wrangler secret put OPENAI_API_KEY --config backend/wrangler.toml
npx wrangler secret put PAYSTACK_SECRET_KEY --config backend/wrangler.toml
# optional: HUBTEL_API_KEY, MOBILE_MONEY_KEY
```

Never commit secrets. `wrangler.toml` only contains non-secret vars.

## 5. Deploy Backend (Worker)

```bash
npx wrangler deploy --config backend/wrangler.toml
# → https://rx-store-api.<subdomain>.workers.dev
# Test:
curl https://rx-store-api.<subdomain>.workers.dev/health
curl "https://rx-store-api.<subdomain>.workers.dev/updates/check?app=pharmagame&currentVersion=1.0&platform=android"
```

## 6. Deploy Web (Pages)

```bash
npm run build
npx wrangler pages deploy dist --project-name=rx-store-web --branch=main
# Set env var in Pages dashboard: VITE_API_URL=https://rx-store-api.<subdomain>.workers.dev/v1
```

## 7. Coexistence Verification

```bash
# Ensure existing apps still resolve
curl https://pharmagame.pages.dev/  # should remain 200
curl https://code-rx-society.pages.dev/  # should remain 200
# Check no binding collision
npx wrangler d1 list | grep -v rx-store  # pharmagame/code-rx DBs untouched
```

## 8. Rollback

Worker rollback (if needed):
```bash
npx wrangler rollback --config backend/wrangler.toml
```
Pages rollback via Cloudflare dashboard → Deployments → Rollback.

## 9. Cost Isolation

All `rx-store-*` resources bill to same account but are independently deletable:
```bash
# ONLY rx-store resources — example cleanup (do NOT run unless decommissioning)
npx wrangler d1 delete rx-store-db --skip-confirmation
npx wrangler r2 bucket delete rx-store-storage
```
